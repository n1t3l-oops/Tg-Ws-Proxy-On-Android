# TG WS Proxy для Android

Локальный MTProto-прокси для Telegram на телефоне. Ядро — [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (MIT, лицензия лежит в `app/src/main/python/proxy/`), запущенное внутри приложения через Chaquopy.

## Как получить APK (без Android Studio)

1. Зарегистрируйся на github.com и создай новый репозиторий (Public или Private).
2. Загрузи в него ВСЁ содержимое этой папки (Add file → Upload files). Папка `.github` тоже должна попасть в репозиторий — если проводник её скрывает, включи показ скрытых файлов.
3. Открой вкладку Actions → «Build APK» → Run workflow. Сборка идёт ~5–10 минут.
4. Внутри завершённого запуска скачай артефакт `TgWsProxy-apk`, распакуй, перекинь `.apk` на телефон и установи (разреши установку из неизвестных источников).

## Использование

1. Открой приложение → «Запустить» (разреши уведомления).
2. «Открыть в Telegram» → подтвердить добавление прокси. Если не сработало: «Скопировать ссылку», отправь её себе в «Избранное» и нажми на неё.
3. Прокси работает в фоне, в шторке висит уведомление с кнопкой «Остановить».

Чтобы Android не убивал прокси в фоне: Настройки → Приложения → TG WS Proxy → Батарея → «Без ограничений».

Если что-то не работает — нажми «Показать лог» в приложении.
