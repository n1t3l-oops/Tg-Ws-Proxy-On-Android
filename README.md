# TG WS Proxy для Android

Локальный MTProto-прокси для Telegram на телефоне. Ядро — [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (MIT, лицензия лежит в \`app/src/main/python/proxy/\`), запущенное внутри приложения через Chaquopy.

## Как получить APK

1. Загрузи содержимое репозитория на GitHub.
2. При каждом push в \`main\` автоматически запускается сборка в Actions.
3. В завершённом запуске скачай артефакт \`TgWsProxy-apk\`, распакуй, перенеси APK на телефон и установи.

## Использование

1. Открой приложение → «Запустить» (разреши уведомления).
2. Нажми «Telegram» для добавления прокси. Если не сработало: скопируй ссылку, отправь её себе в «Избранное» и нажми на неё.
3. Прокси работает в фоне; в шторке есть уведомление с кнопкой «Остановить».

## Если медиа загружаются нестабильно

В приложении есть переключатель «Маршрут медиа»:

- **DC4** — использует \`4:149.154.167.220\`, рекомендованный upstream вариант для первичной диагностики.
- **Авто** — очищает список DC → IP и оставляет выбор маршрута ядру.

После переключения приложение автоматически перезапускает прокси. Сравнивай оба режима в одной сети. Это не гарантирует ускорение: скорость зависит также от сети и доступности узлов Telegram.

Чтобы Android не останавливал прокси в фоне: Настройки → Приложения → TG WS Proxy → Батарея → «Без ограничений».

Для диагностики открой раздел «Журнал работы» и «Сетевая статистика» в приложении.
